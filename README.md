# sunflowermathlab

Bridges Unit 4 Measuring to the nearest 1/4" and line plots.

A free Grade 3 unit: measure to the nearest half and quarter inch, then build a line plot from your own paper sunflower.

**Live site:** https://apesfrep-dotcom.github.io/sunflowermathlab/

| Page | Who | What |
|---|---|---|
| [Ruler Lesson](https://apesfrep-dotcom.github.io/sunflowermathlab/ruler-lesson.html) | Teacher, Day 1 | Projected, teacher-led ruler instruction with notes (press N) |
| [Sunflower Lab](https://apesfrep-dotcom.github.io/sunflowermathlab/sunflower-lab.html) | Students | Self-checking measurement entry, line plot lesson, own-flower line plot, practice. Reads aloud. |
| [Printables](https://apesfrep-dotcom.github.io/sunflowermathlab/Sunflower-Lab-Printables.pdf) | Teacher | Blackline masters: ruler practice, 4 sunflowers, answer key. Copy at 100%. |

Each page is a single self-contained HTML file (fonts and narration audio are embedded), so the site has no build step and no outside dependencies.
